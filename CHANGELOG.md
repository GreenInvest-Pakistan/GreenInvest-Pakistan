# GreenInvest Pakistan changelog

Product-facing release history for the official live calculator and standalone
Windows application. Downloadable files and integrity information are published
on the [release page](https://github.com/GreenInvest-Pakistan/GreenInvest-Pakistan/releases).

## 4.3.0 — 24 August 2026

### Product release

- Publish the separate public release repository without proprietary
  model source or private operator tooling.
- Provide guided recommendation and installer quote-check journeys.
- Include recommendation, plan comparison, solar/inverter/battery sizing,
  seasonal bills, risks, on-demand sensitivity, Monte Carlo, evidence, and
  downloadable reports.
- Enforce desired-bill guardrails instead of presenting an over-limit result as
  compliant.
- Retain the latest Windows draft and completed result between restarts.
- Support report, configuration, evidence, plan, sensitivity, and Monte Carlo
  downloads from the standalone Windows shell.
- Reduce the standalone ZIP to approximately 152 MiB while preserving the full
  calculation engine and bundled browser runtime.
- Add complete Python-package licence collection, LGPL/GPL texts, Qt/PySide
  relinking information, exact source locations, and Chromium notices.
- Add a packaged interface smoke test and a real packaged recommendation test.
