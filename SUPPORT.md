# Support

| Need | Best route |
| --- | --- |
| Use GreenInvest now | [Open the live calculator](https://greeninvest-pakistan.vercel.app) |
| Install on Windows | [Release and verification guide](RELEASES.md) |
| Report a product problem | [Open a structured issue](https://github.com/mbax0009/GreenInvest-Pakistan/issues/new/choose) |
| Report a security problem | [Submit a private vulnerability report](https://github.com/mbax0009/GreenInvest-Pakistan/security/advisories/new) |

## Before opening an issue

1. Confirm that the live calculator or the latest Windows release is being used.
2. For Windows, extract the complete ZIP before running `GreenInvest.exe`.
3. Retry with the same non-identifying inputs and note the visible error text.
4. Check [known limitations](KNOWN-LIMITATIONS.md).

Use the repository's issue forms for reproducible product or documentation
problems. Include the operating system, GreenInvest release version, journey
used, expected behaviour, and actual behaviour.

Do **not** attach electricity bills, addresses, account numbers, owner tokens,
private installer quotations, saved-plan files, or screenshots containing
personal information. Describe the issue with synthetic values instead.

Sensitive security problems belong in a
[private vulnerability report](https://github.com/mbax0009/GreenInvest-Pakistan/security/advisories/new),
not a public issue.

This repository cannot provide individual installer selection, structural
approval, electrical sign-off, financing approval, tax advice, or a guaranteed
investment outcome.
